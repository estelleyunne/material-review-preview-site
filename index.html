🔧 问题诊断与修复

问题 1：审核按钮不显示

根本原因：后端 _effective_material_access 函数返回的权限数据缺少 pageAccessLevel 字段，但前端 materialCapability 函数需要该字段判断权限级别（必须是 'manage' 才能显示审核按钮）。

问题 2：素材无法审核和推送

影响范围：由于审核按钮缺失，用户无法执行审核操作，导致审核通过的视频无法推送到 TikTok Ads 后台。

❌ 修复前

def _effective_material_access(page_level, material): normalized = normalize_material_access(material) if page_level not in {"read", "manage"}: return normalize_material_access({}) # 缺少 pageAccessLevel 字段 return {**normalized, "capabilities": capabilities}

前端无法判断权限级别，审核按钮不显示

✅ 修复后

def _effective_material_access(page_level, material): normalized = normalize_material_access(material) if page_level not in {"read", "manage"}: return {**normalize_material_access({}), "pageAccessLevel": "hidden"} # 添加 pageAccessLevel 字段 return {**normalized, "capabilities": capabilities, "pageAccessLevel": page_level}

前端可以正确判断权限，审核按钮正常显示
